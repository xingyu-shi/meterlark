# Repository workflow

Follow [CONTRIBUTING.md](CONTRIBUTING.md) for branch, review, and release rules.

- Work on a feature branch based on the latest `main`; use the `codex/` prefix.
- Push the feature branch to `xingyu-shi/meterlark` and open a PR targeting `main`.
  Never push directly to `main`.
- Leave the PR for another collaborator's approval. Use a review bypass only when
  a human contributor explicitly requests it for that specific PR.
- Create release tags only from commits already merged into `main`.
